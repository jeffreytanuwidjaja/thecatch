The Catch Science Uploader

Internal tool for uploading shorts to The Catch Science YouTube channel.

Purpose

This application uses the YouTube Data API v3 to upload fact-checked science/health Shorts created by the The Catch Science production pipeline. It is not a public-facing service.

Data Access

The app requests the youtube.upload scope to:

  • Upload video files to The Catch Science channel
  • Set titles, descriptions, thumbnails, and visibility

No user data is collected, stored, or shared. Authentication tokens are stored locally on the upload machine only.
